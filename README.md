# Viajes Martínez - Web Oficial

Proyecto desarrollado con **Astro** y **Tailwind CSS**.

## Comandos

- `npm run dev`: Iniciar servidor de desarrollo.
- `npm run build`: Construir para producción.
- `npm run preview`: Ver la versión de producción localmente.

## Estructura

- `src/pages/index.astro`: Página principal.
- `src/components/`: Componentes reutilizables (Hero, Navbar, etc.).
- `src/styles/global.css`: Estilos globales y configuración de temas (Banana Theme).

## Personalización

Para cambiar colores, editar la sección `@theme` en `src/styles/global.css`.
Para editar textos, ir directamente a los componentes en `src/components/`.
